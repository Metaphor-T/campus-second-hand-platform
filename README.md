# 校园二手交易平台

基于 Vue 3、TypeScript、Element Plus 和 Spring Boot 的校园二手交易项目。

## 本次更新：基于成员二版本完善字号与无障碍布局

本次以成员二的 `player-2` 版本为功能基础，在开发副本完成验收与修复后，将已确认代码同步至稳定项目。

- **增加全站字号设置**：标准 100%、大字 125%、特大字 150%、超大字 200%，支持预览、恢复默认和浏览器持久化。
- **统一阅读入口**：使用“阅读设置·字号”；登录注册页融入背景左上角，用户端融入导航，管理员端位于顶部工具区。
- **完善登录注册布局**：保留品牌背景图，大字号和窄屏时自适应排列，补充字段标签及错误提示。
- **调整导航布局**：菜单整体居中，放大后按明确区域排列，恢复各字号下的滚动吸顶效果。
- **修复管理员大字布局**：保持左侧菜单、右侧内容的结构；支持收起/展开菜单、独立滚动和统计卡片自适应，避免右侧内容消失或数值截断。
- **改进交互体验**：退出确认使用居中小窗口；补充键盘焦点、按钮名称、图片替代文字和减少动态效果支持。
- **修复验收发现的问题**：订单详情归属校验、库存扣减和返还、并发取消/退款、分页 100 条兼容及重复审核错误处理。

## 本机配置与运行

后端使用 Java 21 和 Maven，前端验证环境为 Node 24。前端端口 21091，后端端口 21090。

数据库密码不放在最新提交的公共配置中。后端默认使用 `local` 配置，可在本机新建 `api/src/main/resources/application-local.yml`（该文件被 Git 忽略）：

```yaml
spring:
  datasource:
    password: "填写自己的本机数据库密码"
```

也可以通过环境变量 `CAMPUS_DB_PASSWORD` 提供密码。数据库地址和账号按自己的本机环境配置，避免将本机凭据提交到仓库。

后端在 `api` 目录运行 `mvn spring-boot:run`；前端在 `view` 目录安装项目依赖后运行 `npm run dev`。

## 数据库迁移

本次新增订单实际库存扣减数量字段，迁移文件为：

[20261109_order_stock_deducted_quantity.sql](sql/migrations/20261109_order_stock_deducted_quantity.sql)

执行前备份并选择正确数据库。历史订单缺少实际扣减事实时保留 NULL 待核对，取消/同意退款会受到保护，不能根据当前库存盲目回填。测试库数据、上传文件、备份和构建产物不随代码同步。

新环境若使用 `sql/db.sql` 初始化，需要在初始化后执行上述迁移；已有业务数据库应使用增量迁移，避免重新运行包含 DROP TABLE 的初始化脚本。
