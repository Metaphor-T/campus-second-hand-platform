# 首页卡片点击及我的商品筛选对齐测试记录

开发目录：`campus-system-dev`。本次只修改前端，不改数据库、不启动稳定项目；用户验收后按文件清单同步稳定项目，保留各环境的数据库配置、密钥和上传文件。

## 问题与改动

用户首页左侧热门卡片原来只给标题按钮绑定详情跳转，右侧推荐卡片同时给外层与标题绑定，造成两侧可点击范围不同，右侧标题也可能重复处理事件。游客首页热门卡片有相同的标题限定问题。

- 三种卡片统一采用覆盖主区域的原生详情链接，图片、标题、价格和空白区域都进入当前商品详情，鼠标操作与键盘 Enter 行为一致；链接保留真实 href，支持浏览器原生打开方式。
- 标题恢复为展示文本，去掉右侧父容器的重复点击处理，整卡只有一个详情入口。
- 缩略图使用独立原生按钮，不嵌套在链接内部，保持在详情链接上层；点击、Enter 和空格都只切换商品，不跳转。提供商品名称、当前选中状态和清晰的键盘焦点。
- 修复用户首页窄屏样式：不超过 820px 时两张卡片上下排列，避免原来的 100% 宽度卡片仍在一行被压缩，导致内容遮挡。
- 保留桌面布局、图片、价格、排名及缩略图的原有展示风格。

另修复“我的商品”筛选栏在标准 100% 字号下的标签对齐：“标题”“状态”与对应输入框、下拉框垂直居中。样式只作用于该区域的标准字号，其他三档字号仍保持原来的上下布局。

修改文件：`view/src/views/user/UserMarket.vue`、`view/src/views/guest/GuestMarket.vue`、`view/src/styles/accessibility.scss`。

## 手动验收

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| HC01 | 登录后点击左侧热门卡片的图片、标题、价格、空白区域 | 均进入该热门商品详情 |
| HC02 | 点击右侧推荐卡片的同样四个区域 | 均进入该推荐商品详情，每次只触发一次导航 |
| HC03 | 在游客首页操作热门卡片 | 进入游客商品详情页，无需登录 |
| HC04 | 点击任意卡片的其他缩略图 | 仅切换当前商品、排名及选中样式，不离开首页；之后点击主区域进入切换后的商品 |
| HC05 | 用 Tab、Enter、空格操作 | 详情链接 Enter 跳转；缩略图 Enter/空格只切换；有焦点标识，无交互元素嵌套 |
| HC06 | 切换标准及 200% 字号，并在桌面、平板和窄屏重复上述操作 | 点击区域正确，没有页面横向溢出，窄屏两张用户卡片上下排列 |
| HC07 | 标准字号进入“我的商品”，观察标题、状态标签 | 标签与控件垂直居中；切换 125%、150%、200% 后仍为原来的上下布局 |
