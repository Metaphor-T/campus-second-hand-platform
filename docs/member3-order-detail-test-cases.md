# 成员三：订单详情与交易时间线验收记录

日期：2026-11-10。开发与测试目录：`D:\ProgrammeProject\campus-system-vue3\campus-system-dev`。

本次增加独立订单详情页，集中展示商品、订单金额、买卖双方、收货信息、备注、当前状态和交易时间线。订单中心的订单编号和“查看详情”均可进入；详情页会显示下一步处理方，并可跳回订单中心定位本单，继续使用原有交易操作。

## 展示口径与边界

- 时间线读取现有 `create_time`、`pay_time`、`ship_time`、`receive_time`、`cancel_time`，按业务流程排列，时间为北京时间。
- 已有时间、阶段已到但时间未保存、历史记录不完整、待处理节点分别显示文字标记。不会把 `update_time` 或当前时间当作缺失节点的发生时间。
- 待付款由买家处理，待发货由卖家处理，待收货由买家处理，售后由卖家处理；已完成、已取消没有待处理步骤。状态与节点矛盾时提示核对，不指定下一位处理人。
- 旧数据没有独立售后申请时间、完整状态变更日志和取消操作人，页面明确标注，不推断具体操作人。未来增加事件记录后才可完整展示操作人、时间和原因。
- 下单金额来自订单快照；商品标题、图片、交付方式和地址来自当前关联资料，可能随资料修改而变化，页面明确将交付方式标为“商品当前支持的交付方式”，不能据此还原历史实际安排。
- 地址只有归属本单买家时才显示；创建订单时也会校验地址归属。无可用地址时提示与对方核对自提或其他安排。
- 付款为模拟记录，不接入真实支付或退款。不新增数据库表、不变更数据库结构，本次无需迁移 SQL。
