# 成员一：独立个人中心与校园资料

> 2026-11-11 发布说明：旧 SQL 已统一为 `sql/db.sql`。本页涉及旧迁移或核对脚本的步骤只保留为历史测试记录，不再作为当前导入步骤；请按[数据库安装说明](database-installation.md)在空库导入完整快照。

本次开发、测试仅在 `campus-system-dev` 和独立测试库 `campus_system_dev_test` 完成。验收后的稳定项目同步按文件清单执行，保留本机配置、上传文件与既有 Git 历史；校园资料表使用单独的增量迁移，不复制测试业务数据。

## 功能与范围

- 登录普通用户后，从右上角头像菜单选择“个人中心”，或访问 `/user-home/profile`。头像菜单只保留个人中心和退出登录，修改密码统一从个人中心进入。
- 展示头像、登录账号、昵称、手机号、性别、注册时间和普通用户身份。账号保持只读；昵称用于展示，账号用于登录。
- 新增学校、学院、学号，均为选填，可保存或清空。校园资料为本人自填，不表示实名认证或学校认证，不用于授予访问权限；不接入学校系统。
- 学号最多 32 位，支持字母、数字、横线和下划线；学校和学院各最多 100 个字符。手机号选填，填写时为以 1 开头的 11 位数字，只做格式校验，不显示已验证标识。
- 校园资料独立存入 `user_campus_profile`，不加入公共卖家资料、用户列表、JWT 或浏览器长期存储。仅本人接口与受控管理员资料接口返回这些字段。
- 头像只在选择后本地预览，点击“保存资料”时再和其他修改统一提交。取消不调用保存/上传接口；数据库提交失败会回滚并清理本次新头像，原头像保留。
- 头像支持实际内容与扩展名相符的 JPG/PNG、最多 2MB、单边 4096 像素、总像素 1600 万。后端解码并重新编码，按用户隔离路径存储。
- 修改密码需要原密码、新密码和再次确认；新密码 8—64 位。成功后退出当前浏览器登录，新密码可登录；取消不修改密码。
- 保存后及时更新导航栏头像与昵称，保存失败保留草稿供重试；手机号和校园资料可明确清空。

## 相关权限收口

为防止个人中心资料被旧入口绕过，普通用户的管理性增删改、列表和他人详情接口改为管理员权限；旧个人修改入口绑定当前登录身份。旧的立即写入头像接口停止使用，旧密码地址也要求原密码等完整参数。管理员注册入口不再对游客开放，管理员个人修改/改密接口校验身份与本人 ID；公开路由白名单按完整路径匹配，保留普通用户注册、正常登录和游客浏览。

本次是个人中心及相关资料权限改进，不声明完成全部账号安全改造。密码继续兼容现有存储方式；密码哈希迁移、JWT 密钥配置、全局会话撤销等应另行设计、测试，不能把“当前浏览器退出”理解为已撤销所有设备的旧凭据。

## 数据库迁移

`20261110_user_campus_profile.sql`（历史脚本，已合并） 只新增独立资料表，关联基础账号并在账号被删除时级联清理对应校园资料，不复制或覆盖其他表。

开发库迁移结果：[执行与重复执行验证](accessibility-evidence/profile-migration-results.json)。执行账号为 `campus_dev_test`，数据库为 `campus_system_dev_test`；原有 15 张表执行前后校验值相同，重复执行成功。老账号没有校园资料行时仍能登录并读取个人中心，字段显示“未填写”。

验收同步须将前后端与本迁移成组处理。在稳定库执行前应单独确认目标库和备份，仅执行本迁移新增资料表，不写入测试账号或校园信息。应用回退时不要直接删除新表，以免丢失已填写的校园资料。

|---|---|---|

| P02 | 查看未填写的学校、学院、学号 | 显示“未填写”，标注本人填写，不出现已认证身份标识 |

| P04 | 修改昵称、学校等，选择头像但不保存 | 头像只本地预览，导航栏和数据库资料保持原值 |
| P05 | 点击取消修改 | 草稿与头像预览取消，原资料不变 |
| P06 | 同时修改资料并选择有效头像，再保存 | 一次提交成功，导航栏立即更新；刷新页面后仍保留 |
| P07 | 将手机号和校园资料清空后保存 | 对应字段清空，刷新后显示未填写，而非恢复旧值 |
| P08 | 输入空昵称、错误手机号或非法学号 | 明确提示，不保存无效资料；直接调用接口也有校验 |
| P09 | 学校/学院超 100 字、学号超 32 位 | 页面长度限制，后端拒绝非法输入 |
| P10 | 选择非图片、伪造扩展名或超过 2MB 的文件 | 拒绝保存，不替换原头像；原文件不被删除 |
| P11 | 模拟保存接口失败 | 页面保留草稿和错误提示，可重试或取消；服务器原资料不变 |
| P12 | 分别在 1440/1024/768/320 宽度、四档字号查看及编辑 | 页面不横向溢出，输入项与文字完整可操作 |

| P15 | 原密码错误、新密码太短或两次不一致 | 提示具体原因，不修改密码 |

| P17 | 正确修改密码 | 当前浏览器退出登录；原密码不能再次登录，新密码可登录 |
| P18 | 游客访问个人资料接口 | 401，不能取得任何个人资料 |
| P19 | 普通用户请求其他用户校园资料/管理接口 | 403，不能读取或修改他人数据 |
| P20 | 在本人更新请求中伪造 id、账号、身份或封禁状态 | 仅更新当前用户允许的资料字段；目标账号及身份不能被修改 |
