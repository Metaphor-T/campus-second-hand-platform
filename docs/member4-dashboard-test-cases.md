## 变更与口径

| 项目 | 原行为 | 本次行为 |
|---|---|---|
| 普通用户 | 直接统计 base_user，含管理员 | 必须有关联的 user 身份且无 admin 身份，按基础账号去重；包含禁用账号 |
| 日期选择 | 趋势支持 90/365/3650 天，其他图表不联动 | 默认近 30 天，可选择近 7/30/90 天、自定义 1—366 个自然日；采用北京时间 |
| 累计和期间 | 界面未明确区分范围 | 累计概览保持全量；期间卡片、图表和明细跟随所选日期 |
| 订单归期 | 图表范围不一致 | 按下单时间归组，状态取查询时的当前值；不是支付或完成时间流水 |
| 成交订单/件数 | 分类按订单 COUNT，却显示“件” | 当前已完成状态为 3；订单数 COUNT，成交件数 SUM(quantity)，分别显示 |
| 实付额 | 仅完成订单汇总，页面解释不足 | 明确为已完成订单 pay_amount 合计，含运费；不称真实营收或结算额 |
| 分类统计 | INNER JOIN 丢失缺失关联，最多取十类 | 保留未分类/商品已删除记录；图表前十类，明细包含全部分类；显示商品条目与成交件数占比 |
| 趋势 | 去掉所有新增均为零的日期 | 每个自然日保留，无新增补零 |
| 平台健康评分 | 平均商品评分被称为“平台响应度”等 | 改为五项定义明确的业务比例，展示分子、分母；没有分母时显示“暂无样本” |
| 读取一致性 | 五个独立请求分别取数 | GET /stats/dashboard 一次返回；只读 REPEATABLE_READ 事务内读取 |
| 数据核对/错误 | 无对应明细，失败主要打印控制台 | 三类图表有键盘可展开的明细表；失败可重试，旧数据保留时间和范围；首次失败不伪造零值 |

时间范围包含开始日与结束日，SQL 使用 `create_time >= start AND create_time < end + 1 day`。用户/商品/订单分别使用自身创建时间。累计中创建时间为空的记录不能归入期间；已删除记录无法恢复统计。历史区间展示的是当前数据库记录的状态和分类，不是历史状态快照。

五项业务比例：

1. 下单用户占比：期间下单的普通用户去重人数（含后续取消）/截至结束日已注册普通用户。
2. 发布用户占比：期间发布商品的普通用户去重人数/截至结束日已注册普通用户。
3. 订单完成占比：期间新建且当前已完成订单/期间全部新建订单。
4. 可见评价好评占比：期间新增可见 4—5 星评价/期间新增可见有效评价（1—5 星）。
5. 完成订单评价覆盖率：当前已有可见有效评价的期间已完成订单/期间已完成订单，按订单去重，评价时间不限。

|---|---|---|

| D05 | 展开统计口径 | 普通用户、条/单/件、含运费、订单当前状态、分类与日期的定义可读 |

| D07 | 开始日期晚于结束日期 | 给出提示，不发起统计请求，不改变上次成功数据 |
| D08 | 超过 366 天或选择未来结束日期 | 前后端均拒绝，页面保留原数据；366 天允许 |

| D10 | 切换分类图表两个指标、展开分类明细 | 商品按条、成交按件，完成订单按单；明细包含全部类别，合计与期间卡片一致 |
| D11 | 展开订单状态表格 | 各状态数量之和等于期间新建订单；没有样本时占比不显示伪造的 0% |
| D12 | 查看业务比例 | 可看到分子/分母及定义；4—5 星占比不以“未评价商品”作为分母 |
| D13 | 四档字号及 1440/1024/768/320 宽度查看 | 日期控件、卡片不横向溢出，数字不截断；表格只在自身区域滚动；图表文字随字号变化 |

| D15 | 模拟接口失败后重试 | 首次失败不显示假零值；刷新失败保留明确标注的旧数据；重试成功后更新 |

| D17 | 查看订单状态环图和颜色图例 | 各非零部分显示占比；列表包含全部状态及百分比；使用原有固定状态颜色 |

## 自动验证

后端测试包含日期、比例计算、权限、错误响应、今日角标与期间独立性和真实 MySQL 查询夹具验证。完整后端测试共 142 项通过（含本次新增 19 项），失败 0、跳过 0。真实 MySQL 测试仅使用 `campus_dev_test` 连接 `campus_system_dev_test`，启动时检查库名和数据库身份；所有测试数据在一个事务中回滚，回滚后再次核对业务总数和金额。测试库自增序列可能留有正常空号。

已知夹具验证包含：管理员/双重身份/缺少普通身份不计入，禁用普通账号保留、重复身份不重复计数；首日零点、末日最后一秒与次日零点；闰日；一单多件；未完成/取消/退款不计成交；超过十类完整保留；缺失商品/分类；隐藏/无效评价排除；未知订单状态不丢失。夹具期间预期 20 单、其中已完成 14 单、成交 20 件、实付 102.30 元，查询结果匹配。

浏览器专项共 27 项通过：16 个宽度/字号组合，3 个快捷日期，以及今日角标与期间独立性、胶囊滑块键盘/动画、历史已完成订单和成交件数图表、自定义闰日/空样本、无效日期、失败刷新及重试、首次失败和服务端日期限制。16 个组合还检查三个角标数值和范围、角标不遮挡主数字、四板块等宽等高、展开表格前后布局不变、滚轮仅滚动当前板块、彩色图标及各状态百分比；均对本页进行自动无障碍扫描，无所测规则违规。不等同于完整 WCAG 认证。前端类型检查与生产构建通过。
