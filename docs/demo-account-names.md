## 已有数据库

先备份目标库，在正确的数据库中完整执行 `sql/migrations/20261110_demo_account_names.sql`，检查输出为“账号名同步完成”。脚本没有固定数据库名，仅处理初始化数据中 ID 为 2、3、5、6 的四个账号。

- 全部旧名、全部新名，以及部分已改名的状态均可执行；重复执行不会继续修改数据。
- 只更新 `base_user.account`，不覆盖各库自己的昵称、密码、头像或业务数据。
- 若目标名被其他用户占用，或四个 ID 不符合预期，整组账号均不改动，并在查询结果中提示检查。不要通过删除冲突用户的方式强行执行。
- 当前本机开发测试库与稳定库已经完成改名，无需重新导入初始化文件。

若希望已有数据库的五个演示昵称也使用上面的展示方案，再执行 `sql/migrations/20261110_demo_user_nicknames.sql`，检查输出为“演示昵称同步完成”。昵称脚本只改 `username`，会替换这五个账号当前的自定义昵称；需要保留各环境现有昵称时不执行。它也会检查 ID、账号及同名账号冲突，支持重复执行。

本次同步 GitHub 只更新初始化 SQL、昵称迁移与文档。稳定库已经符合上面的昵称方案，开发测试库保留各自现有昵称；不批量改写本机数据库。
